Cas base_v3bl_dom2 porté vers OpenFOAM 12 (fondation), version installée sur les grappes de l'Alliance (FIR).
Même maillage, mêmes schémas et mêmes solveurs linéaires que base_v3bl_dom2 (OpenFOAM 8).
Changements de syntaxe :
  - controlDict : application foamRun + solver incompressibleFluid (au lieu de pimpleFoam) ;
  - dynamicMeshDict : réglages du maillage tournant dans un sous-dictionnaire mover ;
  - transportProperties remplacé par physicalProperties (viscosityModel constant) ;
  - cyclicAMI n existe plus : AMI1 et AMI2 restent des patchs, couplés par createNonConformalCouples (nonConformalCyclic) ;
    conditions sur leurs parties non couvertes : movingWallSlipVelocity pour U, zeroGradient ailleurs.
IMAGE_DOCKER et PAQUET_APT : pas d image Docker officielle pour la version 12, le workflow installe le paquet openfoam12 (dl.openfoam.org) dans Ubuntu 24.04.
